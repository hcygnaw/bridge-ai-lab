## 二、各关设计思路与本地测试结果

### 第 1 关「小水沟」（`submission/level1.json`）
- **思路**：全木桁架结构，尽量用低成本木杆（70 元/米）配合合理分段路面，末期通过贪心删除冗余木杆进一步压价。
- **测试**：`bridge.py check 1` 合法，造价 **3702 / 10000**（路面 2250、木杆 1232、节点 220）；`bridge.py run 1` 3/3 通过，0 断裂，峰值受力 96%。

### 第 2 关「大峡谷」（`submission/level2.json`）
- **思路**：30 米大跨度采用钢木混合桁架/拱式承重，先确保超载面包车过关，随后通过逐根材料降级（钢杆→钢索/木杆、删除冗余杆件）将造价从 18764 压至 **16397**。
- **测试**：`bridge.py check 2` 合法，造价 **16397 / 26000**；`bridge.py run 2` 2/2 通过，0 断裂，峰值受力 94%。

### 第 3 关「早高峰」（`submission/level3.json`）
- **思路**：针对双向密集多车流，使用低成本木桁架主结构加关键节点钢杆补强；末期发现原设计有 2 根冗余木杆会在测试中断裂但不影响通车，直接删去后再裁剪 1 根木杆，既降价又实现 0 断裂。
- **测试**：`bridge.py check 3` 合法，造价 **8708 / 18000**；`bridge.py run 3` 3/3 通过，0 断裂，峰值受力 97%。

### 第 4 关「过船」（`submission/level4.json`）
- **思路**：双叶开启桥（bascule）+ 汽笛传感器 + 两侧红绿灯联锁控制：听到汽笛立刻红灯拦车、延迟抬升双叶液压杆让船通过，船过后合拢并转绿灯。末期对固定侧跨与拉索进行贪心降级/裁剪，造价从 23241 大幅压低至 **18764**（节省 4477 元）。
- **测试**：`bridge.py check 4` 合法，造价 **18764 / 25000**；`bridge.py run 4` 2/2 通过，0 断裂，峰值受力 94%。

### 第 5 关「钱不够」（未提交）
- **尝试与进展**：
  - 解决了左侧深坑 `[-11, -0.5]` 边缘台肩碰撞问题（在 `(-0.55, 0.04)` 设切线过渡节点）。
  - 24 米河道采用了 10 段路面 + 双链连续钢索悬链线（不额外增设节点，靠跨两段弦向钢索并联分担拉力），把总造价压到 9874 元以内，且曾跑出 `s1`/`s2` 全程 0 断裂（峰值 70%–80%），但因纯受拉悬链线缺乏抗弯刚度，车辆在坡度变化处触发翻车/触地（`VFAIL 2`）。
  - 本关禁用木杆（`wood`），在最后阶段未能同时把深坑段与河道段的造价控制在 10000 元以内并消除翻车，因此按规则未提交未通过的半成品。

### 第 6 关「地狱关」（未提交）
- **尝试与进展**：
  - 构造了平直路面 + 墩顶斜撑（将 12 米边跨缩成 7.5 米钢拱 + 钢索吊杆）+ 中央 6 米双叶液压开启桥，造价 19678 / 20000。
  - 通过对桥墩 `A4=(12,-2)` 取力矩平衡（$\sum M_{A4}=0$）定位了核心瓶颈：5000 kg 重卡驶上悬臂开启叶时，若背索锚在 `y=0` 路面（距 `A4` 仅 2 米力臂），路面水平拉力必然超过 90 kN 上限（实测 91–92 kN，仅超 1–2%）；将背索改接到上拱高节点后成功消除了 `t=6.5s` 的首次断裂，但在 20000 预算约束下尚未完成三个场景全部通过的闭环调试。

### 第 7 关「攻防」决赛桥（`submission/final_bridge.json`）
- **思路**：第 7 关不比造价只比胜率，因此充分利用 26000 预算构建高冗余抗冲击堡垒：
  - 采用类似悉尼海港大桥的**双肋钢桁拱**（上下双层钢拱肋 + 全部 ≤2.5m 短钢腹杆，避开长压杆屈曲，发挥钢杆 140 kN 满额抗压 / 180 kN 抗拉能力），所有吊杆为纯受拉钢索。
  - 桥面全部位于拱下方，无低矮横向压杆可被捣蛋车顶撞；用己方 2.5 吨液压重锤捣蛋车实测攻击后，发现原版在 1/3～2/3 跨处抗瞬态冲击偏弱，遂在对称四分点加装 4 根斜向钢索拉结，升级后彻底扛住己方重锤双连砸且 **0 断裂**。
- **测试**：`bridge.py check final` 合法，造价 **25922 / 26000**；`bridge.py run final` 1/1 通过，0 断裂，车队峰值受力 76%；对阵己方 `saboteur.json` 0 断裂桥方胜。

### 第 7 关「攻防」捣蛋车（`submission/saboteur.json`）
- **思路**：**2498 kg 预抬升液压重锤冲击车**（极简 3 节点 3 杆结构，零自损风险）：
  - 2 个驱动轮间距 1.6m（底部钢杆连接），顶部节点装载 **2160 kg 配重**，由两根 `"H"` 组液压杆支撑，总质量 2498 / 2500 kg、造价 4516 / 6000。
  - 出发即以最大速度 10 m/s、加速度 4 m/s² 冲刺，同时预伸长液压杆至 `ratio=1.35` 蓄能；当车头过 `x=13.5m` 和 `x=20.0m` 时，分别以最大液压速度 3.0 m/s、加速度 5.0 m/s² 猛缩至 `ratio=0.60` 并迅速反弹，在桥面后半跨制造巨大瞬态冲击（既可压垮常规桁架/拱桥，又因高速冲刺能在桥塌于身后时安全冲过 `x=36m` 终点线）。
- **测试**：对阵未加斜拉索的 25922 元双肋钢桁拱桥时，**5.7 秒完好到达终点**，直接砸断 26 根杆件并判定捣蛋车胜；对阵加固后的己方决赛桥时也能 5.7 秒完好到达（无自毁/翻车/超限问题）。

## 三、规则理解与疑问

1. **钢杆抗压上限的平台截断**：规则中给出了欧拉压杆屈曲公式 $900/L^2$，实际测试中发现钢杆在短长度下存在约 140 kN 的抗压上限截断（与材料抗拉 180 kN 不同）；建议在规则材料表中直接明示各材料的抗压上限值，便于选手精确校核短压杆。
2. **第 5 关禁用材料说明**：第 5 关禁用 `wood` 是在 `level5.json` 与 `check` 报错中体现的，若在关卡描述文案中也显式列出可用/禁用材料会更清晰。
3. **第 7 关捣蛋车碰撞边界**：规则说明车身节点会碰路面（半径 0.1），未明示捣蛋车是否会与桥上非 `road` 杆件（如钢拱、木腹杆）碰撞；经实测与常规车辆一致，仅与 `road` 和地形发生接触。

## 四、怀疑的模拟器现象

- 未发现确定的物理引擎 Bug。唯一较敏感的现象是：**纯受拉悬链线桥面**（如第 5 关）在多车或重车经过节点折角时，即使所有杆件均未断裂，也较容易在局部下凹折角处触发 `VFAIL 2`（翻车/车身触地），对路面节点高程连续性非常敏感。
